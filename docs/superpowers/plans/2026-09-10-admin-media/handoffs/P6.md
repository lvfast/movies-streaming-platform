## Review fixes applied

### Round 1

1. **P6-C library filters/sorts the whole catalog** — `FilmLibraryPage` fetches every page
   (`fetchAllMovies`, size 100) and applies search/lifecycle/media-state filters plus sort over the
   full list, then paginates client-side. The `managementMode` filter was replaced with a media-state
   filter; the table shows a `Media` column instead of `Mode`.
2. **P6-B role revocation after silent refresh** — `streaming-api.ts` exports
   `subscribeAuthUser`/`notifyAuthUser`; `refreshSession` notifies the refreshed user; `SessionProvider`
   re-derives `user`/`isAdmin`.
3. **"Save and continue" on a new film navigates to the created draft** — after `createMovie` the
   editor navigates to `/admin/movies/{id}` (replace), so `reloadLatest` always has a `movieId`.
4. **P6-G drawer navigation and 390px table** — `AdminLayout` gained a mobile drawer; the 390px
   table keeps the essential columns.

### Round 2 (second review)

1. **Drawer keyboard accessibility** — the closed drawer is now `visibility: hidden` (not focusable,
   not in the accessibility tree) in addition to `translateX(-100%)`. Opening moves focus to the
   `Close navigation` button; closing (X, scrim, or Escape) returns focus to the toggle; the scrim is
   an `aria-hidden` div, leaving exactly one accessible "Close navigation" control.
2. **Form validation matches server limits** — the form is `noValidate` and `submit()` now validates
   `releaseYear` (1888–2200) and genre count (≤10) in addition to title/slug, so "Save and continue"
   no longer bypasses the limits with `type="button"`.
3. **Pagination URL clamping** — an out-of-range `page` is clamped to `[0, totalPages-1]`; the
   pagination control and "Page X of Y" use the clamped value, and a `useEffect` rewrites the stale
   URL. `/admin/movies?page=99` on a one-page catalog now shows "Page 1 of 1" with a valid, non-empty
   table.
4. **Media-state copy is now honest** — the column/filter are labelled "Active media" (values
   `Active`/`None`) derived from `activeMediaVersionId`, not "media state". True per-version
   processing state requires the P7 contract and is deferred to post-MVP.
5. **Loading matches the visual spec** — the library loading state now renders skeleton rows instead
   of a spinner (reduced-motion honored), and the visual spec no longer promises a per-row disclosure
   (non-essential columns are hidden at 390px).
6. **Test coverage** — added tests for sort, pagination, out-of-range page clamping, release-year
   limits, drawer focus/Escape, and "403 does not refresh".

### Round 3 (third review)

1. **Drawer focus on navigation** — nav links and "View site" now call `closeMenu()` on click (which
   returns focus to the toggle), and a `menuOpenRef`-guarded `useEffect` closes the drawer with focus
   restore when the pathname changes (browser back/forward). Clicking "Films" while already on
   `/admin/movies` (no pathname change) still closes the drawer. Added tests asserting the toggle
   regains focus after Escape and after following a nav link.
2. **Skeleton no longer clips at 390px** — the skeleton grid collapses to the essential four cells and
   hides the `Released`/`Updated` placeholders inside the 390px media query, matching the real table.
