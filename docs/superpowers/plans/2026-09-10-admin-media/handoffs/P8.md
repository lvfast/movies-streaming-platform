## Integration gaps found by the journey and their regression tests

Each product defect got a focused owning-component test observed red before the fix.

1. **Operator grant crashed in the non-web context** — `SecurityConfiguration` built
   `HttpSecurity`-dependent beans under `--spring.main.web-application-type=none`. Fixed by scoping
   the class with `@ConditionalOnWebApplication(type = SERVLET)`. Regression (was red):
   `OperatorGrantContextTest` (Testcontainers Postgres/Redis, non-web context, asserts the granted
   role and the `ROLE_GRANTED` audit row).
2. **Browser uploads were CSP-blocked and presigned for the wrong port** — the frontend CSP named
   only the gateway origin and the harness never overrode `S3_BROWSER_ENDPOINT` (default
   `http://127.0.0.1:9000`), so the browser's presigned PUTs were refused by `connect-src` and would
   have hit the developer's MinIO. Fixed: nginx template/entrypoint substitute a second origin
   (`MEDIA_STORAGE_ORIGIN`) into `connect-src`; compose.local.yml, `.env.example` and the CI nginx
   validation pass it; the harness sets `S3_BROWSER_ENDPOINT` and `MEDIA_STORAGE_ORIGIN` to the
   disposable MinIO's loopback port. Regressions (was red): policy test
   `test_nginx_csp_names_the_declared_storage_origin_for_browser_uploads` and harness tests
   `test_disposable_environment_presigns_browser_storage_at_the_loopback_endpoint`,
   `test_minio_cors_environment_allows_uploads_only_from_the_web_origin`.
3. **MinIO has no bucket-level CORS API** — `PutBucketCors` answers `NotImplemented` (reproduced
   against `quay.io/minio/minio:latest` outside the harness). Fixed with the documented server-level
   equivalent: the disposable MinIO gets `MINIO_API_CORS_ALLOW_ORIGIN` scoped to the journey's web
   origin (verified by a live OPTIONS preflight probe returning 204 with the right headers). The R2
   bucket-CORS production equivalent is in `docs/runbooks/admin-media-rollout.md`.
4. **Review page could not read the movie revision** — nginx weakens the ETag to `W/"0"` when it
   gzips the JSON response, and `revisionFromEtag` accepted only the strong form. Fixed to accept an
   optional `W/` prefix. Regression (was red): `admin-api.test.ts`
   "extracts the numeric revision from a gzip-weakened ETag".
5. **Attach was unreachable** — the review page's fallback selection marked the first READY artwork
   "Selected" and disabled its Attach button, so the explicit attach command (and its
   `MOVIE_ARTWORK_ATTACHED` audit event) could never run. Fixed: "Selected"/disabled now reflect an
   explicit pointer only; the fallback still completes the publish payload. Regression (was red):
   `admin-media.test.tsx` "keeps the attach action available for artwork that is only the fallback
   selection".
6. **Spec/harness defects, not product defects**: journey spec now scopes the job-detail badge
   (`.admin-job-detail …`), advances the player to ≥1 s before pausing (whole-second progress
   semantics), and the harness accepts `MEDIA_ACCEPTANCE_BROWSER_CHANNEL` so CI can pin Playwright's
   Chrome for Testing (test: `test_browser_channel_override_wins_over_installed_browser_detection`).
   Repository policy tests now read `frontend/nginx.conf.template` (the tracked `nginx.conf` was
   replaced earlier) and skip worktree-deleted files.

## Follow-up: full-suite test-infrastructure fix (2026-09-14)

The backend full-suite defect recorded in the P8-F gate and post-MVP is fixed. Root cause (confirmed
by bytecode inspection and a minimal pair reproduction): Spring Framework 7.0.9 keys the context
cache on the set of `@DynamicPropertySource` methods, so `AdminFoundationHttpTest` and `MediaTokenTest`
— the only `ApiTestSupport` subclasses without a method of their own — shared one cached context
while Testcontainers restarted the static Postgres container on a new port per class; the reused
context pointed at the stopped container's port. Fix: `@DirtiesContext(classMode = AFTER_CLASS)` on
`ApiTestSupport` evicts each class's context, so no cached context outlives its containers (also
closes the leaked contexts and their reconnect noise). Evidence:
`AdminFoundationHttpTest,MediaTokenTest` 14/14 green (was 7 errors; minimal reproduction observed
red before the fix) and full suite `Tests run: 158, Failures: 0, Errors: 0, Skipped: 14`
BUILD SUCCESS (`artifacts/fix-pair-foundation-mediatoken.log`, `artifacts/fix-full-backend.log`).
